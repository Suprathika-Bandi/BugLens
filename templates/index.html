How BugLens Works

BugLens implements a multi-layer analysis pipeline:

  1. Syntax Verification: Validates Python token grammar with AST parsing.
  2. AST Inspection: Maps classes, functions, scopes, and variable contexts.
  3. Static Rules: Evaluates 14+ static detectors for mutable defaults, dead code, suspicious conditions, and security risks.
  4. Runtime Sandbox: Runs isolated code in a subprocess with resource and timeout limits.
  5. Health Score: Weights detected issues to produce an objective 0-100 quality score.
  6. Local Ollama AI: Connects to your local llama3.2 instance to generate root cause explanations and corrected code.

BugLens Quick Reference

Keyboard Shortcuts:

  • Ctrl + Enter or Cmd + Enter: Run analysis
  • Tab: Insert 4 spaces in the code editor

Configuring Local Ollama:

Run Ollama on port 11434 with model llama3.2:

ollama pull llama3.2
ollama serve

Environment overrides: OLLAMA_MODEL and OLLAMA_URL.

Stack: Python 3, Flask, Python AST, Subprocess Sandbox, Local Ollama HTTP API, HTML5/CSS3.
